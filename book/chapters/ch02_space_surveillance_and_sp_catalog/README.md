# Chapter 2: Global Space Surveillance Networks, Orbit Determination & Special Perturbations (SP)

## Chapter Scope
Contrasts analytic mean-element propagation (TLE / SGP4) against high-precision numerical Special Perturbations (SP: EGM-96 geopotential, JB2008 thermospheric drag, solar radiation pressure, Gauss–Jackson integration) and 6x6 state error covariance generation.
