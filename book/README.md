# ORBITAL-AI — هندسة تفادي الاصطدام الفضائي والذكاء الاصطناعي المداري

🚀 **التطبيق التفاعلي المباشر:** [افتح ORBITAL-AI على Streamlit](https://orbital-esa-collision-avoidance-3ewp7cecpuqb3kh6kmmbse.streamlit.app/)

مرجع هندسي من ستة فصول يأخذ القارئ من فهم بيئة الحطام في المدار الأرضي المنخفض، إلى إنتاج بيانات الاقتران CDM، ثم بناء نموذج إنذار مبكر، وأخيرًا تحويل التنبؤ إلى تحليل فيزيائي ومناورة تفادي قابلة للمراجعة.

> **فكرة الكتاب:** رحلة واحدة متصلة: نرصد البيئة → ننتج المعرفة المدارية → نفهم سجل الاقتران → نصوغ قرار الخطر → نبني نموذجًا موثوقًا → نتحقق فيزيائيًا من خيارات المناورة.

## ابدأ القراءة

1. اقرأ الفصول بالترتيب؛ فالمفاهيم والاختصارات تتراكم عمدًا من فصل إلى التالي.
2. استخدم روابط التنقل أعلى وأسفل كل فصل للانتقال بين أجزاء الكتاب.
3. الرسومات المشار إليها داخل النص موجودة في [`Figures/`](Figures/).
4. ملفات الصور الأصلية المضمنة داخل مستندات المصدر محفوظة أيضًا في [`Figures/embedded/`](Figures/embedded/).

## الصور والروابط

- جميع الصور المشار إليها تستخدم مسارات نسبية، ولذلك تعمل داخل GitHub دون روابط محلية خاصة بجهازك.
- أسماء ملفات الصور محفوظة كما وردت في الأرشيف لتسهيل تتبع أصل كل شكل.
- إذا أضفت صورة جديدة، ضعها في `Figures/` واستخدم رابطًا نسبيًا مثل:
  `![وصف واضح للصورة](Figures/figure_6_1_hcw_rtn_and_stm_geometry.png)`
